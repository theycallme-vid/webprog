------ TAG HTML -------

🔹 1. Struktur Dasar
  <html> → root dokumen HTML
  <head> → metadata (tidak tampil di halaman)
  <body> → isi utama halaman
  <title> → judul tab browser

🔹 2. Metadata & Resource
  <meta> → info tambahan (charset, viewport, dll)
  <link> → menghubungkan file eksternal (CSS, icon)
  <style> → CSS internal
  <script> → JavaScript
  <base> → base URL untuk link relatif
  <noscript> → konten jika JS mati

🔹 3. Sectioning (Struktur Halaman)
  <header> → bagian atas (logo/nav)
  <nav> → navigasi
  <main> → konten utama
  <section> → bagian konten
  <article> → konten mandiri (blog, berita)
  <aside> → sidebar
  <footer> → bagian bawah
  <h1> – <h6> → heading
  <hgroup> → grup heading (jarang dipakai)

🔹 4. Text & Formatting
  <p> → paragraf
  <br> → baris baru
  <hr> → garis horizontal
  <pre> → teks dengan format tetap
  <blockquote> → kutipan panjang
  <q> → kutipan pendek
  <abbr> → singkatan
  <address> → alamat
  <cite> → referensi karya
  <b> → bold (tanpa makna semantik)
  <strong> → penekanan penting
  <i> → italic
  <em> → penekanan
  <u> → underline
  <mark> → highlight
  <small> → teks kecil
  <del> → teks dihapus
  <ins> → teks ditambahkan
  <sub> → subscript
  <sup> → superscript
  <code> → kode inline
  <kbd> → input keyboard
  <samp> → output program
  <var> → variabel
  <dfn> → definisi istilah
  <time> → waktu/tanggal
  <bdi> → isolasi arah teks
  <bdo> → arah teks

🔹 5. List
  <ul> → unordered list
  <ol> → ordered list
  <li> → item list
  <dl> → description list
  <dt> → istilah
  <dd> → deskripsi

🔹 6. Link & Navigasi
  <a> → hyperlink
  <area> → area dalam image map
  <map> → map untuk gambar
  
🔹 7. Media (Gambar, Audio, Video)
  <img> → gambar
  <figure> → container media
  <figcaption> → caption
  <picture> → responsive image
  <source> → sumber media
  <audio> → audio
  <video> → video
  <track> → subtitle

🔹 8. Table (Tabel)
  <table> → tabel
  <caption> → judul tabel
  <thead> → header tabel
  <tbody> → isi tabel
  <tfoot> → footer tabel
  <tr> → baris
  <td> → sel
  <th> → header sel
  <col> → kolom
  <colgroup> → grup kolom

🔹 9. Form & Input
  <form> → form
  <input> → input data
  <textarea> → input teks panjang
  <button> → tombol
  <select> → dropdown
  <option> → pilihan dropdown
  <optgroup> → grup option
  <label> → label input
  <fieldset> → grup form
  <legend> → judul grup
  <datalist> → autocomplete list
  <output> → hasil output
  <progress> → progress bar
  <meter> → indikator nilai
